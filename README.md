# DATS 6401: Week 6 Homework
## Graph & Network Data: F1 Teammate Network

**Author:** Soumay Patidar
**Course:** Visualization of Complex Data (DATS 6401)
**Dataset:** Formula 1 World Championship: Ergast Database

### What This App Does

Builds an interactive teammate network from F1 race data:

- Nodes = drivers, Edges = teammates (same constructor, same season)
- Size encodes degree or betweenness centrality
- Color encodes detected community
- Sidebar widgets: year filter, layout, degree threshold, centrality toggle
